# Boot: power button → Chrome's restored tab loaded, ~59s (2026-10-18)

Measure: `journalctl --user -t boot-timeline` (one line per boot, home/scripts/boot_timeline.mjs).
Seconds since kernel start; firmware+loader come before the kernel.

## Where the time goes (baseline)
```
power ──┬─ firmware (BIOS)  7.5s ██████████████▌            not software-fixable
        ├─ loader+kernel+initrd 3.5s ███████
        ├─ early userspace  ~5s  ██████████
        ├─ home-manager     5.7s ███████████  blocks login
        │    └ claude plugin git fetch, no network yet 1.4s ✂ skipped at boot
        ├─ getty Type=idle  4.9s █████████▊ ✂ Type=simple
        ├─ sway init        7.4s ██████████████▊ (2 GPUs' EGL, fonts, modeset)
        ├─ chrome wrapper  12.7s █████████████████████████▍ ✂ 168 rsyncs → 9
        │    (chrome_sync_ext_settings: 7.5s → 0.84s, warm-cache dry run)
        ├─ chrome start     6.1s ████████████▏ (profile + extensions + tab restore)
        └─ page load        5.6s ███████████  ── t=59.1s

shutdown:
nix-daemon stop  5.6s every time ✂ capped at 2s (determinate-nixd idles, then exits 0)
/home unmount    4-6s  disk writeback, real work
user manager     1.9s
```
Sway → Chrome is sequential by necessity: Chrome needs the Wayland socket, and sway runs config
`exec`s only after its own init (~7.3s after sway start).

## Baseline numbers (boot 945a34f5, before fixes)
```
firmware 7.49 + loader 0.27
initrd .55  userspace 3.24  hm 8.78→14.53  getty 14.56  sway 19.51
sway_session 26.87  chrome_wrapper 26.85  chrome_exec 39.54  tab_nav 45.68  tab_load 51.33
```
| gap | cause | fix |
|---|---|---|
| chrome_wrapper→exec 12.7s | `chrome_sync_ext_settings.sh` ran 168 separate rsyncs (56 ext entries × 3 profiles) | one rsync per (dir, profile) with an include list (dry-run warm: 7.5s → 0.84s) |
| getty→login ~4.9s (every boot) | `getty@.service` is `Type=idle` → waits up to 5s for the job queue | `Type=simple` for tty1 |
| hm 5.7s blocks login (`Before=systemd-user-sessions`) | claudePluginSync 1.4s of git fetches with no network yet | skipped while `is-system-running` = starting |
| | rest of HM: nix sanity/realise 1.4s, checkLinkTargets 1.5s, linkGeneration 1.2s | `vars.speed_over_safety`: HM no longer `Before=systemd-user-sessions`, runs alongside login |
| sway→sway_session 7.4s (3.5s on older boots) | EGL init on both GPUs ~2s, `font pango` 1.4s, modeset 1.2s | not touched |
| chrome_exec→tab_nav 6.1s | Chrome profile/extension/tab-restore startup | not touched |
| firmware 7.5s | BIOS POST | BIOS fast-boot setting (manual) |

Toggle verbose systemd logging (boot + late shutdown on console): `vars.debug`.

Shutdown (logind power-off → last journal line, 10-16s): nix-daemon stop 5.6s every time
(determinate-nixd exits 0 after idling; capped to 2s), /home unmount 4-6s (writeback, real).
